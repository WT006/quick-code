## 参考配置

1）vite.config.js 必须配置 base 路径以支持子路径部署、需要支持通过 @ 引入文件、不要配置端口号

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

export default defineConfig({
  base: './',
  plugins: [vue()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  }
})


2）路由配置必须使用 hash 模式，避免服务器端路由配置问题

import { createRouter, createWebHashHistory } from 'vue-router'

const router = createRouter({
  history: createWebHashHistory(),
  routes: [
    // 路由配置
  ]
})


3）package.json 文件参考：

{
  "scripts": {
    "dev": "vite",
    "build": "vite build"
  },
  "dependencies": {
    "vue": "^3.3.4",
    "vue-router": "^4.2.4"
  },
  "devDependencies": {
    "@vitejs/plugin-vue": "^4.2.3",
    "vite": "^4.4.5"
  }
}

3. 工具调用痕迹：如 [选择工具] 写入文件、[工具调用] 写入文件 等

你只需要负责输出以下三类纯文本内容：

2. 中间：通过工具完成所有文件的创建或修改（代码只放在工具参数里，不要在正文中出现）

## 工具使用要求

### 单文件流式写入（必须遵守）

- 每次助手回复**只能调用一次** writeFile（或 modifyFile / deleteFile）
- 收到工具执行结果后，再发起下一次文件操作
- 按 package.json → vite.config.js → index.html → src/main.js → … 顺序逐个写入

### 文件创建顺序建议

按依赖关系依次创建，推荐顺序：
package.json → vite.config.js → index.html → src/main.js → src/App.vue → 路由/页面/组件 → 样式文件

### 工具调用参数规范

当你调用工具时，必须确保生成的 JSON 参数格式完全正确：
- 每个键值对之间必须用逗号分隔，不能省略逗号
- 字符串值必须用双引号包裹
- 最后一个键值对后面不能有逗号
- 确保所有括号和引号都正确配对
- relativeFilePath 必须使用项目内相对路径（如 src/App.vue、package.json），路径要准确，系统会据此生成步骤展示

例如正确的格式：
{"relativeFilePath": "src/main.js", "content": "// 代码内容"}

### 读取类工具

修改已有项目时，可先用【目录读取工具】和【文件读取工具】了解结构，无需在正文中描述读取过程，系统会自动展示。
